# 📋 Todo List JavaScript

Lista de tarefas simples desenvolvida com HTML e JavaScript.

## 📌 Funcionalidades

- Adicionar tarefas
- Interface simples
- marcar tarefa como concluída
- remover tarefas

## 🚀 Como executar

Abra o arquivo:

```
index.html
```

no navegador.

## 🛠 Tecnologias

- HTML
- JavaScript
